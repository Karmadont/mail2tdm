# Сканер-осмотрщик TDM (`scan-tdm.ps1`)

Маленькая безопасная программа для **рабочего компьютера с Windows**. Она заглядывает
в папку, куда установлен TDM Messenger, и составляет отчёт: из чего программа собрана
и есть ли у неё зацепки для подключения других программ (боты, api, токены).

## Что она НЕ делает

- не запускает TDM и вообще ничего не запускает;
- не меняет и не удаляет ни одного файла;
- **не отправляет ничего в интернет**;
- не собирает пароли: длинные «секретные» строки прячет звёздочками;
- **не требует прав администратора**.

## ВАЖНО про кодировку

Файл сохранён в кодировке **UTF-8 с BOM** — это специальная невидимая пометка
в начале файла, по которой Windows PowerShell понимает, что русские буквы внутри
записаны современным способом.

**Без этой пометки PowerShell читает русский текст как мусор и выдаёт ошибки
вида «Непредвиденная лексема "}"».** Именно это и случилось в первый раз.

Поэтому: копируй файл целиком (через флешку, сетевую папку или вложением).
Не пересоздавай его копированием текста в Блокнот — так пометка потеряется.

## Как запустить

1. Скопируй файл `scan-tdm.ps1` на рабочий компьютер, на Рабочий стол.
2. Нажми «Пуск», напечатай `PowerShell`, открой **Windows PowerShell**.
3. Вставь в синее окно эту команду и нажми **Enter**:

```
powershell -ExecutionPolicy Bypass -File "C:\Users\akritskiy\Desktop\scan-tdm.ps1"
```

Если сканер напишет, что не нашёл папку TDM — укажи её вручную. Как узнать путь:
найди ярлык TDM → правой кнопкой → **«Расположение файла»** → скопируй адрес из
проводника и запусти так:

```
powershell -ExecutionPolicy Bypass -File "C:\Users\akritskiy\Desktop\scan-tdm.ps1" -Path "вставь_путь_сюда"
```

## Что потом

Когда сканер закончит, на **Рабочем столе** появится файл `TDM_scan_report.txt`.
Открой его, скопируй весь текст и пришли мне в чат — по нему я пойму, есть ли у TDM
пригодная для нас зацепка.
