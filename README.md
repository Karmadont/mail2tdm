# mail2tdm

Переправляет письма с задачами из почты Outlook в закрытый мессенджер TDM.

## Что это такое

Идея простая: задачи приходят в рабочую почту Outlook, а работа ведётся в мессенджере TDM.
Вручную копировать письма в мессенджер долго и легко что-то потерять.
Этот проект должен делать это сам: находить в почте письма с задачами и отправлять
их содержимое в TDM.

## Статус

Выяснено главное: **у мессенджера есть официальный Bot API**. Значит, задача
решается разрешённым способом — через собственного чат-бота, а не обходными путями.

Доступ к боту выдаёт техподдержка мессенджера по заявке с корпоративной почты.
**Заявка отправлена, ждём токен.** Пока токена нет, отправлять некуда.

Готов «скелет» решения: макрос для Outlook (папка `outlook/`) и проверялка
связи (`tools/tdm-check.ps1`). Оформление сообщений и проверка на живом боте —
следующий шаг, после получения доступа.

## Как запустить

Полная пошаговая инструкция — в файле [outlook/README-outlook.md](outlook/README-outlook.md).

Коротко:

1. Получить токен бота у техподдержки мессенджера.
2. Создать файл настроек `%APPDATA%\mail2tdm\config.ini` по образцу
   `outlook/config.example.ini`.
3. Проверить связь: `tools/tdm-check.ps1`.
4. Вставить макрос в Outlook (`outlook/Mail2TDM.bas`).

**Первый запуск — только в тестовом режиме** (`TestMode=1`): программа ничего
не отправляет, а лишь записывает в журнал, что *было бы* отправлено.

## Настройки и пароли

Все пароли, ключи и токены хранятся **только** в файле `.env` в этой папке.
Никогда не вписывай их прямо в код и не пересылай в переписке.

- `.env` — твой личный файл с настоящими паролями. Он **не** попадёт на GitHub:
  об этом заботится файл `.gitignore`.
- `.env.example` — образец: те же названия настроек, но без значений.
  Он попадает на GitHub, чтобы было видно, какие настройки вообще нужны.

Когда дойдём до настройки, скопируй образец в рабочий файл:

```bash
cp .env.example .env
```

и впиши значения в `.env`.

## Структура папки

```
mail2tdm/
├── README.md      — этот файл: что за проект и как с ним работать
├── .gitignore     — список того, что не выкладывать на GitHub
├── .env.example   — образец файла с настройками (без паролей)
├── outlook/       — макрос для Outlook (основное решение)
│   ├── Mail2TDM.bas              — код: отбор писем, оформление, отправка
│   ├── ThisOutlookSession.vba.txt— "сторож" новых писем
│   ├── config.example.ini        — образец настроек (без токена)
│   └── README-outlook.md         — пошаговая инструкция по установке
└── tools/         — вспомогательные программы (Windows, PowerShell)
    ├── tdm-check.ps1       — проверка связи с ботом и список его каналов
    ├── scan-tdm.ps1        — "осмотрщик" установленного приложения TDM
    ├── inspect-asar.ps1    — чтение внутренностей приложения TDM
    └── README-scanner.md   — как пользоваться осмотрщиком
```

## Где хранятся токен и настройки

Настоящий файл настроек лежит **на рабочем компьютере**, а не в репозитории:

```
%APPDATA%\mail2tdm\config.ini
```

Там же журнал работы `mail2tdm.log`. Репозиторий публичный, поэтому токен,
журналы, письма и документацию мессенджера сюда класть нельзя — это перечислено
в `.gitignore`.
