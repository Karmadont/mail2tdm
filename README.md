# mail2tdm

Переправляет письма с задачами из почты Outlook в закрытый мессенджер TDM.

## Что это такое

Идея простая: задачи приходят в рабочую почту Outlook, а работа ведётся в мессенджере TDM.
Вручную копировать письма в мессенджер долго и легко что-то потерять.
Этот проект должен делать это сам: находить в почте письма с задачами и отправлять
их содержимое в TDM.

## Статус

Проект только что создан. Кода пока нет — есть только описание и заготовка
для настроек. Технология (язык программирования) ещё не выбрана.

## Как запустить

**Пока никак — запускать нечего.** Здесь появится пошаговая инструкция,
когда мы выберем технологию и напишем первый рабочий кусок кода.

Чтобы этот раздел не был выдумкой, он специально оставлен пустым.

## Настройки и пароли

Все пароли, ключи и токены хранятся **только** в файле `.env` в этой папке.
Никогда не вписывай их прямо в код и не пересылай в переписке.

- `.env` — твой личный файл с настоящими паролями. Он **не** попадёт на GitHub:
  об этом заботится файл `.gitignore`.
- `.env.example` — образец: те же названия настроек, но без значений.
  Он попадает на GitHub, чтобы было видно, какие настройки вообще нужны.

Когда дойдём до настройки, скопируй образец в рабочий файл:

```bash
cp .env.example .env
```

и впиши значения в `.env`.
